How it works

Send a winner. Get champions back.

  1. Send your winner

    Your best-performing ad or post, plus anything we should know: the offer, the season, what’s changed.

  2. We build on it

    New hooks, angles, formats and sizes, plus photos and video. Each request is delivered within 24 hours, Monday to Friday.

  3. Run it, then repeat

    You run the new versions. The one that wins becomes the next thing we build on. No ad account access needed.

Ad rules worth knowing

Meta restricts side-by-side before-and-after comparisons for weight loss, so transformation ads need care. We lean on energy, coaching and community instead, which tend to be more distinctive anyway.

General guidance, not legal advice. Platform rules change, so check Meta’s current Advertising Standards before you run anything.
